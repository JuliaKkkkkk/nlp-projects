# **NLP Projects Collection**

Добро пожаловать в мою коллекцию NLP-проектов, созданную в рамках магистратуры по компьютерной лингвистике в СПбГУ! Здесь вы найдёте разнообразные практические эксперименты — от настройки токенизаторов и семантического кластерного анализа до обучения эмбеддингов с помощью Word2Vec и глубокого синтаксического разбора.

**Структура репозитория**

Каждый проект оформлен в отдельной директории, где есть исходный код, краткое описание, а также поддиректории parse/ и output/ для входных и выходных данных.

Enjoy 💫
